# 예전에 연동 키트를 받은 분께 — 무엇이 바뀌었고 무엇을 하면 되나

예전 키트(2026-09-24 ~ 10-09 판)로 받는 쪽을 만들었다면, **공개 측에서 고치거나 지운 기준정보가
우리 쪽에 그대로 남아 있을 수 있습니다.** 그동안 공개 측이 보내기 시작한 것(관계 · 바뀐 식별자 ·
안 보이게 된 것 · 다시 받으라는 신호)을 예전 키트가 모르거나 다르게 처리했기 때문입니다.

## 남아 있을 수 있는 것

| 증상 | 까닭 |
| --- | --- |
| 같은 항목이 옛 식별자 · 새 식별자 **두 줄**로 있다 | 식별자가 바뀐 것(`renamed_from` · `previous_keys`)을 무시했다 |
| 공개 측에서 지운 항목이 계속 살아 있다 | 처음부터 다시 받아도 「이번에 안 온 것」 을 정리하지 않았다 |
| 지워지거나 합쳐진 항목에 **관계(선)가 매달려** 있다 | 공개 측은 그 선을 「끊긴 선」 으로 보내지 않는다 — 받는 쪽이 끊어야 한다 |
| 다시 받다가 실패한 뒤 항목이 **사라졌다** | `reset` 이 오면 먼저 비우고 받았다 |
| 관계 수신이 커서 오류 하나로 **통째로 멈췄다** | 404 를 오류 코드로 가르지 않았다 |
| 관계(선)가 **아예 없다** | 2026-09-24 판은 객체만 받았다 |

판마다 무엇이 바뀌었는지와 내 키트가 어느 판인지 알아보는 법은 `CHANGES.md` 에 있습니다.

## 할 일 — 둘 중 우리 경우

### A. 키트의 `sp_core_pull.py` 를 그대로 돌리고 있다

1. 야간 수신을 잠시 끕니다.
2. `out/` 폴더를 통째로 복사해 둡니다(되돌릴 자리).
3. `sp_core_pull.py` · `check.sh` · `README.md` 를 새 것으로 덮어씁니다. **`config.ini` 는 그대로**
   둡니다. 나머지 새 파일(`00-START-HERE.md` · `01-AI-GUIDE.md` · `UPGRADE.md` · `CHANGES.md` ·
   `testbed/`)도 같은 폴더에 둡니다.
4. 판을 확인하고 처음부터 한 번 다시 받습니다.

   ```bash
   python sp_core_pull.py --version        # sp_core_pull {KIT_VERSION}
   python sp_core_pull.py --config config.ini --full
   echo $?                                  # 0 이면 끝
   ```

   끝까지 받은 뒤 이번에 안 온 것을 정리합니다 — 화면의 「안 와서 정리 N」 이 맞춰진 수입니다.
   끝나는 값이 `2` 이고 「정리하지 않았습니다」 가 찍혔으면, 가진 것의 절반 넘게 안 와서 멈춘
   것입니다. 토큰 범위가 바뀌지 않았는지 공개 측에 확인한 뒤, 정말 줄어든 것이면
   `--full --allow-shrink` 로 한 번 더 받습니다.
5. 야간 수신을 다시 켭니다. 끝나는 값이 `0` 이 아니면 알리게 해 두십시오.

`sp_core_pull.py` 의 `save_rows()` 를 고쳐 우리 DB 로 보내고 있었다면, 그 고친 부분은 옮기지 말고
B 로 가십시오. 새 판의 받는 쪽은 `save_rows()` 하나가 아니라 여러 곳(식별자 옮김 · 선 끊기 · 정리)에서
사본을 바꿉니다.

### B. 우리 플랫폼 안에 받는 기능을 따로 만들었다(직접, 또는 AI 로)

1. 이 폴더로 예전 키트 폴더를 바꿉니다(예: `docs/sp-core/`).
2. AI 에게 아래 문장을 그대로 붙여 넣습니다.

   ```text
   docs/sp-core/ 를 새 연동 패키지로 바꿨어. 01-AI-GUIDE.md 와 CHANGES.md 를 읽고,
   우리 플랫폼의 기존 Standard Platform 코어 수신 기능을 지시서 §5 의 규칙 16가지와
   하나씩 대조해 줘. 고치기 전에 빠지거나 다르게 한 것을 표로 먼저 보여 줘.
   그다음 고치고, testbed 시험장 8단계를 모두 통과시켜 줘. 마지막으로 운영 데이터를 맞추도록
   처음부터 다시 받기를 한 번 실행하고, 정리된 건수를 보고해 줘.
   ```

3. AI 의 보고에서 확인합니다.

   - [ ] 시험장 8단계 모두 통과
   - [ ] 처음부터 다시 받기 결과(정리된 건수 · 결과 상태)
