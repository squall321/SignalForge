1. **Postgres 루프백 trust → scram** — dev pg_hba 의 루프백 TCP(127.0.0.1 · ::1) trust 줄만 scram-sha-256 으로, 다시 읽기.
   서비스 · 스크립트는 모두 비밀번호를 넘긴다(확인함). 새 박스도 같게 — initdb 인자.
2. **백엔드 dev 만 루프백** — `apptainer/backend.def` 가 `API_HOST` 를 읽게(기본 0.0.0.0 그대로) 이미지를 다시 짓고, dev `.env`
   만 127.0.0.1. 포털 nginx 는 127.0.0.1:18000 으로 닿는다. 새 이미지는 Drive 로 나간다(cae00 동작은 안 바뀜).
3. **옛 기본 비밀번호 걷어내기(60곳까지 모두)** — 코드 · 문서 · 시험 · CI 의 옛 DSN 기본값을 지우고 DATABASE_URL 이 없으면 바로
   멈추게. `.env.example` 의 Postgres · Redis 비밀번호는 비우고, up.sh 는 비어 있으면 멈추며 만드는 법을 알려 준다.
4. **11-14 에 만든 옛 비밀번호 백업만 지우기** — `~/.config/signalforge/env.bak-20261114-{pg,redis}` · `/etc/redis/*.bak-20261114`.
5. **경쟁사 서브레딧 글을 검색 브랜드 범위에만** — 데이터는 그대로. 브랜드 · 기기로 찾을 때(애플 워치 · 에어팟 · 가민 워치) ·
