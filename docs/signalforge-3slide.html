Cross-Signal — "불량으로 잡히기 전에 여론이 먼저 우는가"
VOC 의 발열·배터리 부정 급증(예: S25 performance 부정율 30%)을 QINGS 불량 리포트의 선행지표로. 반대로 QINGS 가 놓치는 미신고 UX 불만을 VOC 가 보완.
PHASE 1 · 정합
스키마 연결
  • 불량코드 ↔ VOC 카테고리 매핑
  • 제품·모델·시기 키 정렬
PHASE 2 · 상관
선행지표 탐지
  • 부정 급증 → 불량 시차 분석
  • "먼저 우는" 패턴 학습
PHASE 3 · 예측
조기경보
  • LLM 교차 질의·근거 자동첨부
  • 차기 모델 설계 피드백

※ QINGS 연계는 향후 계획(개념 설계). 실제 스키마는 사내 협의 후 확정. 본 자료의 시장 데이터·차트는 모두 실측값입니다.
