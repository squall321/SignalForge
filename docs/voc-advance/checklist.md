## Phase 4 — 소스 집중도 가중 (원안 재정의)

원안(매체 복제 증폭 제거)은 **실측으로 기각**. 교차플랫폼 완전중복이 0.038%(125/327,480)에
불과하고 최근 90일 VOC 는 user 89.7% / media 10.3% 다. 매체 다운웨이팅은 Spearman 0.935 로
신호를 거의 바꾸지 않는 반면, **플랫폼 집중도 가중은 n≥20 조합의 46%를 10계단 이상 이동**시킨다.
진짜 증폭은 매체 복제가 아니라 단일 커뮤니티 쏠림이었다(voc_defects 의 33%가 hackernews 단독).

- [x] 증폭 규모 실측 → 원안 기각, 집중도 가중으로 재정의
- [x] 유효 플랫폼 수(1/HHI) 산출을 탐지 SQL 에 내장
- [x] 단일 커뮤니티 쏠림(유효 플랫폼 < 2) 배제 가드 + 단위 테스트
