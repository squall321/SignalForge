# 시맨틱 검색 2단계 — 임베딩 벡터 + LLM 개념 추론 (2026-10-17)

## 계획

1단계(온톨로지)는 사전에 있는 표현만 개념으로 바꾼다. 2단계는 사전 밖의 말을 잡는다.

| 층 | 무엇을 잡나 | 실측 |
|---|---|---|
| 온톨로지(1단계) | 사전에 있는 표현·표기 변이 | 같은 뜻 4표기 → 같은 251건 |
| LLM 개념 추론 (qwen2.5:7b) | 은유·완곡 표현 → 증상 키 | '폰이 손난로 같아요' → overheat, 12건 중 11건, 135ms |
| 벡터 유사도 (bge-m3) | 비슷한 문장 | '하루를 못 버텨요 배터리' → 광탈 글 0.79 (한·영 교차) |

LLM 은 증상 개념이 하나도 없을 때만 부르고, 추론 개념은 사전 개념보다 낮게 친다
('하루를 못 버텨요' 를 발열로 본 오답이 있었다). 벡터는 후보 경로이자 순위 신호다.

인프라 — ollama 에 bge-m3(1.2GB) 추가. qwen2.5:7b 는 이미 있다. 벡터는 pgvector 없이
crawler/data/vectors 에 float32 조각 파일로 두고 MCP 가 mmap 으로 읽는다(DB 덤프를 키우지 않는다).

같이 하는 일 — Galaxy A14·A15 카탈로그 추가, 일반명 1세대 태그 2,622건 정리(dry-run 뒤 적용).
