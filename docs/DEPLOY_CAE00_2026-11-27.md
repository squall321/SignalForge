## 2. scram — 소켓 · 루프백도 비밀번호

initdb 기본은 소켓 · 루프백이 trust 라 이 서버의 다른 사용자 · 프로세스가 비밀번호 없이 슈퍼유저로 붙는다. 소켓 파일도
`data/postgres-run/` 에 누구나 쓸 수 있게 있다. 0 · 1절이 끝난 뒤에 한다.

```bash
set -a; source .env; set +a
H=data/postgres/pgdata/pg_hba.conf
mkdir -p ~/.config/signalforge && chmod 700 ~/.config/signalforge
cp -p "$H" ~/.config/signalforge/pg_hba.conf.bak-$(date +%Y%m%d) && chmod 600 ~/.config/signalforge/pg_hba.conf.bak-*
python3 - "$H" <<'PY'
import re, sys, pathlib
p = pathlib.Path(sys.argv[1]); out, n = [], 0
for ln in p.read_text().splitlines(keepends=True):
    m = re.match(r"^(\s*(?:local|host)\s+(?:all|replication)\s+.*?)\btrust(\s*)$", ln)
    if m and not ln.lstrip().startswith("#"):
        ln = m.group(1) + "scram-sha-256" + m.group(2); n += 1
    out.append(ln)
p.write_text("".join(out)); print("바꾼 줄", n)
PY
PGPASSWORD=$POSTGRES_PASSWORD apptainer exec instance://sf_postgres psql -h 127.0.0.1 -p $POSTGRES_PORT -U $POSTGRES_USER -d $POSTGRES_DB -Atc "
SELECT pg_reload_conf(); SELECT count(*) FILTER (WHERE auth_method='trust'), count(*) FILTER (WHERE error IS NOT NULL) FROM pg_hba_file_rules;"
# 기대: t · 0|0
```

되돌리기 — 백업을 `$H` 로 복사하고 같은 psql 로 `SELECT pg_reload_conf();`.

## 3. 백엔드 주소(선택)

새 이미지는 `.env` 의 `API_HOST` 를 읽는다(없으면 예전처럼 0.0.0.0). 이 서버의 nginx 가 같은 서버에서 127.0.0.1 로 백엔드에 닿으면
`API_HOST=127.0.0.1` 로 두고 sf-backend 를 다시 띄운다 — SSO 게이트 밖인 `/ws/realtime` 이 바깥에서 닿지 않게 된다. nginx 가 다른
주소로 닿으면 그대로 둔다.

```bash
grep -n "proxy_pass .*:${API_PORT:-8000}" <nginx 설정 경로>     # 127.0.0.1 이면 루프백으로 묶어도 된다
```

## 4. 확인

```bash
set -a; source .env; set +a
env -u PGPASSWORD apptainer exec instance://sf_postgres psql -w -h 127.0.0.1 -p $POSTGRES_PORT -U $POSTGRES_USER -d $POSTGRES_DB -Atc "select 1" 2>&1 | tail -1
env -u PGPASSWORD apptainer exec instance://sf_postgres psql -w -p $POSTGRES_PORT -U $POSTGRES_USER -d $POSTGRES_DB -Atc "select 1" 2>&1 | tail -1
# 기대: 둘 다 'no password supplied'(비밀번호 없이는 거절)
curl -s -o /dev/null -w '%{http_code}\n' "http://127.0.0.1:${API_PORT:-8000}/health"     # 200
ss -ltn | awk -v p=":${API_PORT:-8000}$" '$4 ~ p {print $4}'                            # 3절을 했으면 127.0.0.1 만
# 10분쯤 뒤 — 인증 실패가 없어야 한다(워커의 알림 규칙 평가 · 병합 · 백업이 새 비밀번호로 붙는다)
grep -c "password authentication failed" ~/.apptainer/instances/logs/*/$(id -un)/sf_postgres.err
```
