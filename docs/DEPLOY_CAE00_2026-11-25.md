## 3. 확인 — 게이트웨이로 도구를 부른다

| 부르기 | 기대 |
|---|---|
| `resolve_product_keyword(keyword="<프로젝트 key>")` | `status` resolved · `resolved_via` plm · `core_key.type_slug` plm_project · `matched_by` project |
| `search_voc(keyword="<프로젝트 key> <증상>")` | 결과가 그 제품 범위 · `notes` 에 '프로젝트 … → 과제 n개 · 개발모델 n개 → 제품 n개' 한 줄 · `core_key` 칸 (11-24 에는 범위 없이 1만 건) |
| `search_voc(keyword="<과제코드> <증상>")` | 11-24 와 같은 117건 근처(되돌아가지 않음) |
| `search_voc(keyword="<제품에 못 이은 프로젝트 key> <증상>")` | `total` 0 · `reason` in_core_no_local_data |
| `search_voc(keyword="<증상>", core_type="plm_project", core_key="<프로젝트 key>")` | 두 번째 줄과 같은 범위 · `matched_by` core_key |
| `search_voc(keyword="<제품에 못 이은 과제> <증상>", strict=true)` | `total` 0 · `reason` in_core_no_local_data (strict 없이는 낱말 검색으로 물러나고 그 한 줄) |

들어온 뒤에는 박스 어휘표의 ontology_lookup 다음 호출 줄에 `search_voc(core_type=…, core_key=…)` 를 넣어도 된다(SFO-5).

## 4. `.env` — 할 일 없음(새 박스만)

cae00 의 `.env` 는 11-12 에 고쳤다. 새 박스는 예시대로 `SF_SP_CORE_URL` 과 `NO_PROXY` 의 자리표시를 바꾼다 — 따옴표는 지우지
않는다(`.env` 는 bash 가 읽는다). 코어 주소의 호스트가 NO_PROXY 에 있는지 값을 찍지 않고 보려면

```bash
python3 - <<'PY'
import shlex, urllib.parse
env = {}
for ln in open(".env", encoding="utf-8"):
    if "=" in ln and not ln.lstrip().startswith("#"):
        k, v = ln.split("=", 1)
        try:
            env[k.strip()] = (shlex.split(v, comments=True) or [""])[0]
        except ValueError:                      # 따옴표가 짝이 안 맞는 값 — 그대로
            env[k.strip()] = v.strip()
host = urllib.parse.urlsplit(env.get("SF_SP_CORE_URL", "")).hostname or ""
print("코어 주소", "있음" if host else "없음", "· NO_PROXY 에 그 호스트", "있음" if host and host in env.get("NO_PROXY", "") else "없음")
PY
```
