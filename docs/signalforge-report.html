AI 대화 예시

한 질문이 여러 도구 호출로 이어지고 근거와 함께 답이 돌아옵니다. 실제 도구·실제 수치를 반영했습니다.

SignalForge MCP · Claude
요즘 Galaxy S25 반응 어때? 부정적인 이슈 있으면 알려줘.
→ get_top_issues("GS25") · get_voc_summary("GS25") 전반적으로 긍정입니다(평균 +0.3). 다만 performance 부정율 25.5% 로 가장 높고 display 22.5% 가 뒤를 잇습니다. 'overheating' 언급이 최근 눈에 띕니다.
performance 부정율25.5%
display 부정율22.5%
battery 부정율18.2%
S24랑 비교하면 나아진 거야?
→ compare_products(["GS25","GS24"]) 네, 전 카테고리에서 개선됐습니다. 마감 +0.81(S24 +0.10), 카메라 +0.30(S24 −0.02) 로 격차가 큽니다. S24 에서 부정적이던 카메라 여론이 뒤집혔습니다.
그럼 S25 발열 관련 실제 글 좀 보여줘.
→ search_voc("overheating", product_code="GS25") engagement 순으로 찾았습니다. "Knox Matrix 가 배터리 드레인·발열을 유발한다"(부정)가 상위이며, 업데이트 후 개선됐다는 반응도 섞여 있습니다. 원문 링크 드릴까요?

연계 분석 (Cross-Signal)
"필드 불량으로 잡히기 전에 시장 여론에 먼저 신호가 뜨는가" — VOC 의 발열·배터리 부정 급증을 QINGS 불량 리포트의 선행지표로. 반대로 QINGS 가 놓치는 미신고 UX 불만을 VOC 가 보완.
PHASE 1 · 정합
스키마 연결
  • QINGS 불량 코드 ↔ VOC 카테고리 매핑
  • 제품·모델·시기 키 정렬(389 모델)
  • 공통 분석 축 정의
PHASE 2 · 상관
선행지표 탐지
  • VOC 부정 급증 → 불량 리포트 시차 분석
  • "여론이 먼저 우는" 패턴 학습
  • Crisis 사례 재구성 검증
PHASE 3 · 예측
조기경보·근거
  • LLM 이 두 데이터를 한 질의로 교차 답변
  • 불량 위험 조기 알림 + 시장 근거 자동 첨부
  • 차기 모델 설계 피드백

※ QINGS 연계는 향후 계획(개념 설계)이며 실제 스키마는 사내 협의 후 확정됩니다. 상단 시장 데이터 수치는 실측값입니다.
