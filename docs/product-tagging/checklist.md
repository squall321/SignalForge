# 제품 태깅 — "거의 안 돼 있다"는 말의 정체와 구형 모델 태깅 복구 (2026-10-17)

## 계획

검색할 때마다 AI 가 "제품 태깅이 거의 안 되어 있다"고 말한다는 제보. 원인은 세 겹이다.

1. **도구 설명이 낡았다.** MCP 도구 설명에 6월 수치("미태깅 ~82%", "태깅율 ~18%")가
   박혀 있어 AI 가 그대로 옮긴다. 실측은 활성 991,882건 중 329,870건(33.3%) 태깅.
2. **구형 모델 태깅이 08-28 부터 끊겼다.** 라이브 사전은 활성 제품만 안다. 구형 311종은
   레거시 사전(MODEL_MAP)을 쓰는 Phase C 재태깅에만 의존했는데, 08-28 번역 백로그
   수정이 그 스케줄을 끊었다. 신규 행 중 구형 태깅 비율 8~9% → 1.3~1.8%.
3. **미태깅의 대부분은 원래 태깅할 수 없는 글이다.** 표본 8,000건 중 62% 는 기기어가
   없고 34% 는 브랜드·시리즈만 말한다. 본문에서 모델을 찾을 수 있는 것은 4~5% 뿐.

1·2 를 고친다. 3 은 맥락 태깅(서브레딧·영상 제목) 같은 방침 결정이라 제안만 한다.
